# Semantic store

C2/C3/C4 store rebuildable one-line Turn Semantic Traces, authoritative Trace review feedback, Semantic Session Titles, and editable Semantic Parent suggestions in an application-owned SQLite database. The package never writes Codex SQLite, rollout JSONL, Session metadata, Codex titles, or Native Lineage.

The package owns provider-neutral public-content fingerprinting, generator version invalidation, bounded Trace/Title inputs, idempotent persistence keyed by opaque provider identities, and generator ports without selecting a model runtime.

Semantic Parent uses a bounded, deterministic candidate selector and a provider-neutral structured completion port. AI edges are rebuildable; user-reviewed parent/relation/root placement is authoritative and stored in separate columns preserved across regeneration. Native Lineage remains outside this store's semantic edge and is never overwritten. Forest layout and graph interaction remain excluded.
